# 求职管家 MCP 版

这是供成熟 Agent 调用的多平台自动化执行端。当前支持 BOSS、智联招聘、51job（前程无忧）和猎聘投递。本包不内置聊天 Agent、消息会话、HR 回复、QQ 或微信连接，也不包含 API Key、个人资料、简历、投递历史或浏览器登录态。

## 接入

1. 解压本包。
2. 打开 `daemon/mcp-config.example.json`，将 `<absolute-path-to-job-agent>` 改为本机解压后的绝对路径。
3. 将该 MCP 配置导入支持 MCP 的成熟 Agent，然后重启或重新连接。
4. 让外部 Agent 调用“查看求职状态”，再让它逐个平台打开可见浏览器完成扫码登录。

外部 Agent 负责自然语言规划、研究和记忆；本 MCP 负责四个平台的可见浏览器、登录态保存、长期投递偏好、可恢复任务、真实状态诊断、JD 读取和投递记录。

## 云端模型 API

这不是本地模型。需要后台在批量投递中逐份分析 JD 时，请用户在工作台“设置”里填写并启用自己的云端模型 API。外部 Agent 的模型不会被本项目擅自复用，也不会把 API Key 返回给 MCP 调用方。

## 使用边界

- 启动 MCP 服务不会自动投递；只有外部 Agent 收到明确投递指令并调用开始工具后才会开始。
- 停止会保留已投、已扫描、跳过原因和剩余目标；继续时使用保存的剩余任务。
- 四个平台都通过系统原生 Chrome 的可见窗口运行；出现验证码、登录失效、风控提示或无法确认投递成功时，应停止并人工处理。
- 城市、关键词、筛选、详情和投递都通过页面上的真实控件完成；不能用城市码或查询 URL 代替点击。

MCP 服务由外部 Agent 使用 `node daemon/mcp-server.mjs` 按需启动，不需要双击 `one-click-start.bat`。如果这台电脑没有 Node.js 22+ 或系统 Chrome，或希望使用工作台完成首次配置，可改用独立版启动包准备环境。
